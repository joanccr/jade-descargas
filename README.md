# JADE — descarga para Android

**JADE** es una app para llevar tus finanzas personales y de empresa en un solo sitio.

## Descargar

➡️ **[Descargar la última versión (JADE.apk)](https://github.com/joanccr/jade-descargas/releases/latest/download/JADE.apk)**

Solo funciona en **Android**. En iPhone no se puede instalar así.

## Cómo instalarla

1. Descarga el archivo **JADE.apk** (toca el enlace de arriba y espera a que termine).
2. Ábrelo desde la notificación de descarga o desde la carpeta *Descargas*.
3. Si Android dice *«Por seguridad, tu teléfono no puede instalar apps desconocidas de esta fuente»*: pulsa **Ajustes**, activa el interruptor **«Autorizar apps de esta fuente»** (en algunos móviles dice «Permitir desde esta fuente»), vuelve atrás y pulsa **Instalar**. Solo se pide la primera vez.
4. Puede salir un aviso de **Google Play Protect**, porque JADE no se descarga de la tienda:
   - Si dice que la app no es reconocida o está bloqueada: pulsa **Más detalles** y luego **Instalar de todos modos** (si te ofrece *Analizar app*, también vale).
   - Si pregunta *«¿Activar Play Protect?»* (solo sale si lo tienes apagado): pulsa **Rechazar** y la instalación continúa.
5. Abre JADE, elige **Continuar con Google** y entra con tu cuenta. Cuando te lo pida, crea la carpeta **JADE** y permite las notificaciones.
6. Para recibir las actualizaciones, cuando JADE te pida **«Instalar actualizaciones»**, pulsa **Permitir** y activa el mismo interruptor.

## Actualizaciones

Cuando haya una versión nueva, JADE te lo avisa al abrirla y la instala con un toque (te pedirá confirmar). Tus datos no se tocan.
